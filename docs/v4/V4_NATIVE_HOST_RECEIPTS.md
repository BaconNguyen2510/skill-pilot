### Executable Antigravity procedure

1. Create an isolated workspace and copy beta `skills/skill-pilot` to the
   host's documented project skill directory.
2. Restart or reload skill discovery and record the displayed loaded
   `SKILL.md` path and beta version.
3. Run the 28 unscored prompts generated by
   `eval/v4_host_trial_packet.py --host antigravity` one at a time.
4. For each prompt, preserve a redacted local tool trace showing source status,
   read-only capability discovery, candidate-skill inspection (if applicable),
   no access-control bypass, and the final response.
5. Have independent EN and VI reviewers complete the supplied empty review
   template. Do not record a pass without actual host traces and adjudication.

The required GUI-dependent checks are skill-load confirmation, tool availability,
actual tool calls, and final model behavior. The deterministic CLI and
clean-archive smoke tests cannot substitute for them.
