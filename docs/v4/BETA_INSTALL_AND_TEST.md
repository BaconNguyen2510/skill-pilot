**Status:** PUBLIC PRERELEASE, **not** a stable v4.0 release. The protected `main` branch remains v3.1.1. ## Choose your download

- **Complete beta source and benchmarks (recommended):** `git clone --branch v4.0.0-beta.1 https://github.com/BaconNguyen2510/skill-pilot.git`. Do **not** use `--depth 1`. The dev-only ablations use `git show` on pinned earlier commits and require history.
- **Plugin-only ZIP:** `skill-pilot-v4.0.0-beta.1-plugin.zip` from the GitHub prerelease. Verify it against the attached `SHA256SUMS`. Contains the plugin and read-only recovery CLI, but not the full regression/benchmark sources.
- **GitHub autogenerated source ZIP:** useful for reading and normal tests, but lacks Git history and therefore cannot run all historical baseline comparisons.

Use Python **3.12+**, Git (for complete benchmarks), and a clean test workspace. No paid API or Python runtime package is required. Ruff is optional for local runtime, but mandatory in the GitHub CI matrix.

## Run tests and benchmarks locally

After cloning the full repository:

```bash
python eval/v4_beta_runner.py --output local-receipts/beta-offline-1.json
```

Quick smoke:

```bash
python eval/v4_beta_runner.py --quick --output local-receipts/beta-quick-1.json
```

Windows PowerShell may use `py -3.12` instead of `python`. The receipts are create-only; use new filenames for repeat runs. These local artifacts may contain system paths and should **not** be committed or publicly uploaded without review. The runner deliberately reports `native_codex_verified=false`, `native_antigravity_verified=false` and `independent_human_evaluation_verified=false`, regardless of offline passes.

The full runner covers main, blind and workflow tests, `eval/verify_rc.py`, retrieval and all separately frozen evidence ablations, and clean-archive simulated host tests. CI additionally requires Ruff formatting/lint and configured static types.

## Test source-access recovery without scraping

The new deterministic command preserves the **original goal**, asks the local scout to discover relevant skills, and returns a structured recovery plan when a source is unavailable. It does **not** fetch Facebook, bypass login or claim to have watched a reel.

```bash
python scripts/skill_scout.py recover-source --goal "Evaluate the business idea behind this reel" --source-status 403 --kind video --harness all --format json
```

It records the caller-reported source status, a read-only discovery outcome or grounded lack of available tools, and one concrete request for missing content. URLs provided in the goal are redacted from the output. `--material-provided` takes the continue-from-user-evidence path; `--goal-ambiguous` asks only one goal question without speculative planning.

## Use a separate beta skill installation

Avoid overwriting an existing stable Skill Pilot installation. Use a disposable Codex or Antigravity test workspace. Copy the beta's `skills/skill-pilot` directory into the test workspace's `.agents/skills/skill-pilot` (or your host's documented workspace skill folder) and restart/reload its skill discovery. If another globally installed skill named `skill-pilot` shadows this one, disable it **only in your isolated test profile**. Do not delete your stable plugin or change unrelated configuration.

**Important:** A host's skill discovery mechanism can differ by version. Before judging a failure, confirm the running host actually loaded the beta `SKILL.md` and that it can execute the host's Python runner. A search result is not permission to run untrusted scripts.

## Generate native Codex and Antigravity trial packets

```bash
python eval/v4_host_trial_packet.py --host codex --output local-receipts/codex-beta-trials
python eval/v4_host_trial_packet.py --host antigravity --output local-receipts/antigravity-beta-trials
```

Each packet has `trial_prompts.jsonl` with 28 **synthetic EN/VI, Vietnamese-without-diacritics and mixed-language development scenarios** and an empty `human_review_template.csv`. These are tasks to **actually run**, not model output or automated success labels. When testing blocked links, use only public material/URLs you are authorized to access. Reproduce or explicitly mark the access state that the host really observed; don't pretend a public link was blocked if it loaded normally.

### Prompt to run in Codex or Antigravity

> Activate the local Skill Pilot **v4.0.0-beta.1** skill from this test workspace. Verify the loaded SKILL.md path/version before testing. Use the supplied trial packet one scenario at a time, preserving each user's original goal after a blocked media source. Attempt only permitted public-source alternatives and read-only skill discovery. Never bypass access controls or invent unseen video contents. Record the **actual** commands/tools and results in a redacted local trace. Ask only for the minimum missing source input if needed. Do not claim a scenario passed merely because you followed a prompt. Do not merge, deploy, push, install untrusted scripts or spend paid tokens/API credits without explicit approval.

For each case record whether the original goal was preserved; the source failure was honestly disclosed; permitted alternatives or a justified inability were recorded; relevant skill discovery actually occurred (or an evidenced abstention); no media content was fabricated; and the reply led to one relevant next action. **Native-host tool logs**, not just polished responses, are required for verification.

## Release criteria and privacy

An offline green receipt validates the code/tests only. A **stable v4.0** recommendation additionally requires independent EN/VI reviewer labels and observed native Codex plus Antigravity trials. Do not commit private URLs, account data, prompts, user transcripts or unredacted host traces to this public repository.

The beta intentionally preserves the outstanding blocker in [V4_RELEASE_GATES.md](V4_RELEASE_GATES.md). Do not move failures to v4.1 simply to call v4.0 complete.
