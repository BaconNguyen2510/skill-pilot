# Routing hints

Choose only skills needed for this task; names are search concepts, not requirements.

| Work | Look for | Evidence |
| --- | --- | --- |
| New software | requirements, architecture, relevant framework | acceptance checks and regression results |
| Bug | debugging, affected subsystem | reproduction and fix verification |
| UI | design, accessibility, frontend implementation | rendered behavior and relevant checks |
| Research | domain research, source evaluation | traceable evidence and qualified uncertainty |
| Documents or data | format authoring, domain analysis | opened or validated deliverable and source checks |
| High-stakes decision | domain expertise, risk review | authoritative evidence, assumptions, limits |

Do not select a test, review, deployment, or browser workflow by default if it adds no value or is forbidden. A disabled plugin's cached skill can be read; its tools are not thereby enabled.
